Python SDK: модуль client_utils

Модуль client_utils встроен непосредственно в рантайм клиента. Он предоставляет высокоуровневый идиоматический Python API для работы с чатами, пользователями, сообщениями и интерфейсом.

Информационные методы

client_utils.get_app_version() -> str

Возвращает текущую версию клиента oxDesktop (например, "7.4.3" или "7.4.3.3").

client_utils.get_app_version_full() -> str

Возвращает полное имя сборки с номером суб-версии (например, "7.4.3.3").

Управление сообщениями

client_utils.send_message(peer_id: int, text: str, reply_to: int = 0)

Отправляет текстовое сообщение в указанный диалог или чат.

# Пример отправки сообщения
client_utils.send_message(peer_id=12345678, text="Привет из плагина!")

client_utils.edit_message(peer_id: int, msg_id: int, text: str)

Редактирует текст ранее отправленного сообщения.

client_utils.delete_message(peer_id: int, msg_id: int)

Удаляет сообщение по его идентификатору.

Пользовательский интерфейс (UI)

client_utils.show_toast(text: str, duration_ms: int = 3000)

Отображает нативное всплывающее уведомление (Toast) в нижней части экрана клиента.

client_utils.show_toast("Настройки сохранены!", duration_ms=2500)

client_utils.show_popup(title: str, text: str)

Отображает диалоговое модальное окно с кнопкой закрытия.

Регистрация команд

client_utils.register_command(command: str, callback: callable)

Регистрирует команду в строке ввода сообщений, начинающуюся с символа . или !.

def handle_shrug(ctx):
    # Заменяет .shrug на эмодзи
    client_utils.send_message(ctx["peer_id"], r"¯\_(ツ)_/¯")

client_utils.register_command(".shrug", handle_shrug)
