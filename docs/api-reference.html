API Справочник: модуль client_utils

Модуль client_utils является основным мостом взаимодействия расширений с клиентом. Он автоматически импортируется в окружение каждого плагина.

Уведомления и интерфейс

client_utils.show_toast(text: str) -> None

Отображает всплывающее системное уведомление (Toast) в нижней части активного окна клиента.

client_utils.show_toast("Настройки успешно сохранены!")

client_utils.get_version() -> str

Возвращает текущую версию клиента (например, "7.4.3.3").

current_ver = client_utils.get_version()
print(f"Версия приложения: {current_ver}")

Отправка и обработка сообщений

client_utils.send_message(peer_id: int, text: str, reply_to: int = 0) -> bool

Отправляет текстовое сообщение в указанный чат или канал от имени текущего аккаунта.

# Отправка приветствия в диалог с пользователем
client_utils.send_message(peer_id=12345678, text="Привет из плагина!")

client_utils.get_active_chat() -> Optional[dict]

Возвращает словарь с метаданными текущего открытого диалога (ID, тип чата, название, права) либо None, если чат не открыт.

chat = client_utils.get_active_chat()
if chat:
    print(f"Активен чат: {chat.get('title')} (ID: {chat.get('id')})")

Конфигурация и хранилище плагина

client_utils.get_setting(key: str, default: Any = None) -> Any

Извлекает сохраненное значение настройки из изолированного JSON-хранилища текущего плагина.

client_utils.set_setting(key: str, value: Any) -> None

Атомарно сохраняет настройку плагина на диск.

# Чтение и запись пользовательских параметров
is_enabled = client_utils.get_setting("auto_reply", default=True)
client_utils.set_setting("auto_reply", not is_enabled)
