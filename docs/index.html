Введение в среду плагинов

Клиент оснащён встроенным движком расширений на базе Python 3.11. Плагины позволяют автоматизировать действия в чатах, добавлять команды, интерфейсные кнопки, интеграции с внешними API и модифицировать поведение клиента без перекомпиляции ядра C++.

Архитектура: Среда плагинов полностью совместима со стандартом ExteraGram SDK, обеспечивая плавную миграцию и расширенную поддержку десктопных возможностей.

Форматы плагинов

Движок поддерживает два формата создания и распространения плагинов:

  • Однофайловые плагины (.plugin): идеальны для небольших и средних скриптов, команд и автоматизаций. Весь код и метаданные находятся внутри одного файла.
  • Пакетные плагины (директория или архив .exd): для комплексных проектов с несколькими модулями, ресурсами, иконками и файлом manifest.json.

Однофайловые плагины (.plugin)

Вы можете написать весь плагин в одном-единственном файле с расширением .plugin (или .py). Создавать отдельную папку или manifest.json не требуется — метаданные объявляются прямо в начале файла через глобальные константы: 

# ping_pong.plugin
__id__ = "ping_pong"
__name__ = "Пинг-Понг Бот"
__version__ = "1.0.0"
__author__ = "@oxDesktop"
__description__ = "Простой однофайловый плагин, отвечающий на команду !ping"
__permissions__ = ["ui", "messages.read", "messages.send"]

import client_utils

@client_utils.on_message
def handle_message(message):
    if message.get("text") == "!ping":
        client_utils.send_message(message["peer_id"], "pong! 🏓")
        client_utils.show_toast("Отправлен ответ на !ping")

Поддерживаемые метаданные в .plugin:

  • __id__ (обязательно) — уникальный идентификатор плагина (латиница, цифры, дефис, подчеркивание).
  • __name__ — отображаемое название плагина.
  • __version__ — версия плагина (например, "1.0.0").
  • __author__ — автор (например, никнейм в Telegram).
  • __description__ — подробное описание возможностей.
  • __permissions__ — список требуемых прав (["ui", "messages.read", "messages.send", "network", "files"]).
  • __requirements__ — список зависимостей из PyPI (устанавливаются автоматически).

Пакетные плагины (папка или .exd)

Для крупных проектов плагин организуется в виде папки внутри tdata/plugins/<plugin_id>/ или упаковывается в архив .exd:

my_plugin/
├── manifest.json       # Описание, авторство, версия и права доступа
├── main.py             # Точка входа в плагин (Python 3.11)
├── icon.png            # Иконка плагина в менеджере (опционально)
└── README.md           # Документация плагина

Пример manifest.json:

{
  "id": "my_plugin",
  "name": "Мой плагин",
  "version": "1.0.0",
  "author": "@oxDesktop",
  "description": "Описание плагина.",
  "main": "main.py",
  "permissions": [
    "ui",
    "messages.read",
    "messages.send"
  ]
}

Установка плагинов

  1. Откройте Настройки → Движок плагинов.
  2. Поместите файл .plugin или папку плагина в директорию tdata/plugins/, либо просто перетащите файл плагина в окно приложения.
  3. Плагин появится в списке менеджера без перезапуска клиента.
