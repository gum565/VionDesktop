Введение в среду плагинов oxDesktop

oxDesktop оснащён высокопроизводительным встроенным движком расширений на базе встроенного Python 3.11. Плагины позволяют автоматизировать действия в чатах, добавлять собственные команды, интерфейсные кнопки, интеграции с внешними API и модифицировать поведение клиента без перекомпиляции ядра C++.

Архитектура: Среда плагинов oxDesktop полностью совместима со стандартом exteraGram / exDesktop SDK, обеспечивая плавную миграцию и расширенную поддержку десктопных возможностей.

Быстрый старт: ваш первый плагин

Каждый плагин представляет собой отдельную папку внутри рабочей директории tdata/plugins/<plugin_id>/ или распространяется в виде архива .exd.

Структура файлов плагина:

my_first_plugin/
├── manifest.json       # Описание, авторство, версия и права доступа
├── main.py             # Точка входа в плагин (Python 3.11)
├── icon.png            # Иконка плагина в менеджере (опционально)
└── README.md           # Описание и инструкции для пользователей

Шаг 1. Создание манифеста (manifest.json)

Манифест задаёт уникальный идентификатор и разрешения, необходимые вашему плагину для взаимодействия с клиентом:

{
  "id": "my_first_plugin",
  "name": "Мой первый плагин",
  "version": "1.0.0",
  "author": "@nanodevmc",
  "description": "Приветственный плагин, отправляющий уведомление при запуске.",
  "main": "main.py",
  "permissions": [
    "ui",
    "messages"
  ]
}

Шаг 2. Написание кода (main.py)

Точка входа плагина использует модуль client_utils, автоматически предоставляемый средой выполнения oxDesktop:

import client_utils

def on_start():
    client_utils.show_toast("Плагин успешно запущен в oxDesktop!")

# Регистрация хука на входящие сообщения
@client_utils.on_message
def handle_message(message):
    if message.get("text") == "!ping":
        client_utils.send_message(message["peer_id"], "pong! 🚀")

on_start()

Установка и проверка

  1. Откройте Настройки oxDesktop → Движок плагинов.
  2. Включите Режим разработчика при необходимости локальной отладки.
  3. Поместите папку плагина в директорию tdata/plugins/ или перетащите архив .exd в окно клиента.
  4. Плагин мгновенно появится в списке менеджера без перезапуска клиента.
