Практические примеры плагинов

Коллекция готовых шаблонов с чистым, идиоматическим Python-кодом для быстрого старта вашей разработки.

Пример 1: Быстрый математический калькулятор

Вычисляет выражения прямо при вводе команды .calc <выражение>:

import client_utils

def safe_eval(expr):
    allowed_chars = "0123456789+-*/(). "
    if all(c in allowed_chars for c in expr):
        try:
            return str(eval(expr, {"__builtins__": None}, {}))
        except Exception:
            return "Ошибка вычисления"
    return "Недопустимые символы"

@client_utils.on_send
def handle_calc(msg):
    text = msg.get("text", "")
    if text.startswith(".calc "):
        expr = text[6:].strip()
        res = safe_eval(expr)
        return {"text": f"🧮 {expr} = **{res}**"}
    return msg

Пример 2: Быстрый генератор спойлеров

Оборачивает текст в скрытый спойлер при использовании команды .sp <текст>:

import client_utils

@client_utils.on_send
def handle_spoiler(msg):
    text = msg.get("text", "")
    if text.startswith(".sp "):
        secret = text[4:].strip()
        return {"text": f"||{secret}||"}
    return msg

Пример 3: Логирование в Toast при входе в личку

Приветствует пользователя уведомлением при переходе в секретный чат или личку:

import client_utils

@client_utils.on_chat_opened
def notify_pm(chat):
    if chat.get("is_user"):
        client_utils.show_toast(f"Открыт диалог с {chat.get('name')}")
