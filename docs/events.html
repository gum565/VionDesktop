События и хуки жизненного цикла

Движок плагинов oxDesktop построен на реактивной событийной модели. Плагины могут перехватывать входящие события, модифицировать текст перед отправкой или реагировать на смену активного диалога.

Декоратор @client_utils.on_message

Вызывается при получении любого нового сообщения в доступных чатах:

import client_utils

@client_utils.on_message
def on_incoming_message(msg):
    peer_id = msg.get("peer_id")
    text = msg.get("text", "")
    is_outgoing = msg.get("is_outgoing", False)

    if not is_outgoing and "привет" in text.lower():
        client_utils.show_toast(f"Новое приветствие в чате {peer_id}")

Перехват отправки: @client_utils.on_send

Позволяет модифицировать или форматировать текст перед его передачей на сервер Telegram:

import client_utils

@client_utils.on_send
def filter_outgoing(msg):
    # Превращает кавычки в красивые типографические «елочки»
    text = msg.get("text", "")
    formatted = text.replace('"', '«', 1).replace('"', '»', 1)
    return {"text": formatted}
