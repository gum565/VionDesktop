Событийная модель и перехват (Hooks)

Движок плагинов построен на реактивной событийной модели. Плагины могут перехватывать входящие обновления, фильтровать исходящие сообщения и реагировать на действия пользователя через декораторы.

Декоратор @client_utils.on_message

Срабатывает при получении нового входящего сообщения в любом доступном чате. Требует разрешение messages.read.

import client_utils

@client_utils.on_message
def on_incoming_message(msg):
    peer_id = msg.get("peer_id")
    text = msg.get("text", "")
    
    # Реакция на ключевые слова
    if "секрет" in text.lower():
        client_utils.show_toast("Обнаружено ключевое слово в чате!")

Декоратор @client_utils.on_send

Позволяет модифицировать или отменять отправку исходящего сообщения до передачи в сеть Telegram. Требует разрешение messages.send.

import client_utils

@client_utils.on_send
def on_outgoing_message(msg):
    text = msg.get("text", "")
    
    # Автозамена сокращений
    if text == "спс":
        msg["text"] = "Большое спасибо! 🙏"
        return msg
        
    return msg

События навигации и интерфейса

События переключения экранов и открытия диалогов:

import client_utils

@client_utils.on_chat_opened
def handle_chat_change(chat_info):
    dialog_id = chat_info.get("id")
    title = chat_info.get("title")
    print(f"Пользователь перешёл в чат: {title} ({dialog_id})")
