Спецификация манифеста (manifest.json)

Файл manifest.json является обязательным дескриптором любого расширения. Он информирует клиент о свойствах, авторе, точке входа и запрашиваемых системных правах безопасности.

Полный пример манифеста

{
  "id": "ox_translator",
  "name": "oxTranslator Pro",
  "version": "1.2.0",
  "author": "@nanodevmc",
  "description": "Автоматический мгновенный перевод сообщений в чатах и каналах.",
  "main": "main.py",
  "min_app_version": "7.4.3",
  "permissions": [
    "messages",
    "network",
    "ui"
  ],
  "settings": {
    "target_language": {
      "type": "string",
      "default": "ru",
      "title": "Целевой язык"
    },
    "auto_translate": {
      "type": "boolean",
      "default": true,
      "title": "Автоматический перевод"
    }
  }
}

Таблица полей

Поле Тип Обязательное Описание
id string Да Уникальный латинский идентификатор (a-z, 0-9, _) без пробелов.
name string Да Отображаемое человекочитаемое имя плагина.
version string Да Версия плагина в формате SemVer (например, 1.0.0).
author string Да Имя или Telegram-юзернейм разработчика.
main string Да Относительный путь к точке входа (обычно main.py).
permissions array Нет Список запрашиваемых разрешений безопасности.
settings object Нет Схема настраиваемых параметров, автоматически отображаемая в UI менеджера.

Разрешения безопасности (Permissions)

Принцип наименьших привилегий: Запрашивайте только те разрешения, которые реально требуются для логики плагина. Клиент отображает список прав пользователю при установке.
  • messages — чтение, отправка, редактирование и удаление сообщений в чатах.
  • ui — показ всплывающих подсказок (Toast), диалоговых окон, добавление кнопок в меню.
  • network — разрешение на исходящие HTTP/HTTPS сетевые запросы во внешние сервисы.
  • filesystem — доступ на запись во временную изолированную директорию плагина.
